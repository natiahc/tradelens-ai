Getting Started with Dhan

What to pull from Dhan
  1. Open DhanHQ Trading APIs.
  2. Create your API app in Dhan.
  3. Copy your Client ID.
  4. Generate and copy your Access Token.
  5. Paste them into Broker Credentials below.
  6. Click Save & Activate Dhan.
Where to put it in TradeLens
Broker Name: dhan
Client ID: your Dhan client id
API Key: optional for storage/reference
Access Token: your Dhan access token
Broker Setup: broker name dhan, live or paper as needed
